Kratice se uporabljajo v radijski zvezi, v AIP, v NOTAM in na kartah. Te so najpogostejše.

## Službe in zračni prostor

| Kratica | Pomen |
|---|---|
| ACC | območna kontrola zračnega prometa |
| AFIS | letališka služba informacij za letenje |
| APP | priletna kontrola |
| ATC | kontrola zračnega prometa |
| ATS | službe zračnega prometa |
| CTA | kontrolirano območje |
| CTR | kontrolirana cona (okoli letališča) |
| FIR | območje z informacijami za letenje |
| FIS | služba informacij za letenje |
| GND | kontrola gibanja po tleh (Tla) |
| RMZ | območje obvezne radijske zveze |
| TMA | terminalno kontrolirano območje |
| TMZ | območje obvezne uporabe transponderja |
| TWR | letališka kontrola, stolp (Stolp) |

## Pravila in razmere letenja

| Kratica | Pomen |
|---|---|
| VFR | pravila vizualnega letenja |
| IFR | pravila instrumentalnega letenja |
| VMC | vizualni meteorološki pogoji |
| IMC | instrumentalni meteorološki pogoji |
| CAVOK | vidnost in oblaki v redu (glej stran o vremenu) |
